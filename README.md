# pithos-ime-dictionary

Mozc / Google 日本語入力のユーザー辞書。`dictionaries/*.json` に辞書を書き、`pnpm build` で `dist/*.tsv` に変換する。

## 使い方

```sh
pnpm install
pnpm build
```

`dictionaries/<name>.json` ごとに `dist/<name>.tsv`（BOM 付き UTF-8）が出力される。Mozc / Google 日本語入力の辞書ツールで「管理」→「新規辞書にインポート」から読み込む。

## 辞書の書き方

```json
{
  "entries": [
    { "reading": "ぴとす", "word": "Pithos", "pos": "固有名詞" },
    { "reading": "かおもじ", "word": "(´・ω・`)", "pos": "顔文字", "comment": "サンプル" }
  ]
}
```

| キー      | 必須 | 内容                                                                                                          |
| --------- | ---- | ------------------------------------------------------------------------------------------------------------- |
| `reading` | ○    | 読み。ひらがな・カタカナ・ASCII と一部の記号（ー・、。「」『』〜゛゜）                                        |
| `word`    | ○    | 単語                                                                                                          |
| `pos`     | ○    | 品詞。Mozc の品詞名（`名詞`、`固有名詞`、`人名`、`顔文字`、`短縮よみ` など）。一覧は [src/pos.ts](src/pos.ts) |
| `comment` |      | コメント                                                                                                      |

ビルド時に次を検証し、1 件でも問題があれば何も出力せずに失敗する。

- 必須項目が空でない、タブや改行を含まない、各項目が 300 バイト以内
- 読みに使えない文字がない、`#` で始まらない（TSV ではコメント行になる）
- 品詞が Mozc の品詞名に含まれる
- 同じ読み・単語・品詞の組み合わせが重複していない（カタカナの読みはひらがなに揃えて比較する）

## 開発

```sh
pnpm check     # 型チェック
pnpm lint      # Biome
pnpm knip      # 未使用のファイルと依存
```
